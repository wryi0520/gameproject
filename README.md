# gameproject

Godot 4.7 기반 2D 픽셀 플랫포머 게임입니다.

## 실행 방법

1. [Godot Engine 4.7.1](https://godotengine.org/download) 이상을 설치합니다. (프로젝트가 GL Compatibility 렌더러를 사용하므로 저사양 컴퓨터에서도 잘 돌아갑니다)
2. 저장소를 내려받습니다.
   ```
   git clone https://github.com/wryi0520/gameproject.git
   ```
3. Godot 에디터를 실행하고 "Import" 또는 "가져오기"로 위에서 받은 폴더 안의 `project.godot`를 선택해 프로젝트를 엽니다.
4. 에디터 상단의 실행(▶) 버튼(F5)을 누르면 됩니다. 시작 화면은 `scenes/Title.tscn`(타이틀 화면)입니다.

> `project.godot`에 `addons/godot_mcp` 플러그인이 활성화되어 있는데, 이 addon 폴더는 저장소에 포함되어 있지 않습니다. 처음 열 때 "플러그인을 찾을 수 없다"는 경고가 뜰 수 있지만 게임 플레이엔 지장이 없습니다 (개발 중 AI 도구 연동용 에디터 플러그인일 뿐입니다). 신경 쓰이면 프로젝트 설정 > 플러그인 탭에서 꺼도 됩니다.

## 수정 방법

- **씬(`.tscn`) 수정**: Godot 에디터 좌측 파일 시스템 탭에서 `scenes/` 폴더의 씬 파일을 더블클릭해 열고, 2D 뷰포트에서 노드를 드래그하거나 인스펙터에서 속성을 바꾸면 됩니다. 저장은 `Ctrl+S`.
- **스크립트(`.gd`) 수정**: `scripts/` 폴더의 파일을 더블클릭하면 내장 스크립트 에디터가 열립니다. 저장 후 씬을 다시 실행하면 바로 반영됩니다.
- **새 스테이지 추가**: `scenes/Stage1.tscn` 같은 기존 스테이지를 참고해서 새 씬을 만들고, `scripts/stage_select.gd`의 `STAGES` 배열에 항목을 추가하면 스테이지 선택 화면에 노출됩니다.
- **입력 키 변경**: 프로젝트 설정(`project.godot` > `[input]`) 또는 Godot 에디터의 "프로젝트 > 프로젝트 설정 > 입력 맵" 탭에서 바꿀 수 있습니다.
- 코드를 고친 뒤에는 항상 Godot 에디터에서 F5로 한 번 실행해 에러가 없는지 확인하는 걸 추천합니다.

## 폴더 구조

| 경로 | 설명 |
| --- | --- |
| `scenes/` | 타이틀, 스테이지 선택, 각 스테이지, 나락/죽음/천사방 등 게임 씬(.tscn) |
| `scripts/` | 각 씬/노드에 연결된 GDScript |
| `resources/` | 텍스처 및 애니메이션 프레임 리소스 |
| `assets/` | 스프라이트 이미지 등 원본 에셋 |
| `shaders/` | 커스텀 셰이더 (죽음의 세계 흑백 필터 등) |

### 주요 씬 흐름

```
Title (타이틀)
  └─ 게임 시작 → StageSelect (스테이지 선택)
        └─ Stage1 / Stage2 (플레이 스테이지)
              ├─ 추락 시 → DarkDepths (나락)
              │     └─ 흰 문 → AngelRoom (천사방) → 다시 나락으로
              └─ 사망 시 → DeathRealm (죽음의 세계)
                    └─ 흰 문 → AngelRoom (천사방) → 다시 죽음의 세계로
```

`scripts/game_state.gd`(자동 로드 싱글톤)가 씬 전환 시 페이드/로딩 화면, 일시정지 메뉴, 음량/밝기 설정을 전부 관리합니다.

## 조작법

| 동작 | 키 |
| --- | --- |
| 좌우 이동 | A / D, ← / → |
| 점프 | Space, ↑ |
| 대시 | Shift |
| 공격 | J, 마우스 좌클릭 |
| 상호작용 (거울 세계 전환) | E |
| 스킬 (아군 소환) | Q |
| 대화 (천사 등 NPC) | F |
| 일시정지 메뉴 | Esc |

## 주요 기능

- 이동, 점프, 대시, 공격 등 기본 액션 플랫포머 조작
- 피격 시 무적 시간 및 체력 시스템
- 거울 세계(Mirror World) 전환 기믹
- 아군 소환 스킬 (쿨다운 존재)
- 타이틀 화면(움직이는 구름/눈, 설정 패널) 및 스테이지 선택 화면
- 추락/사망 시 나락·죽음의 세계로 전환, 천사방에서 F키 대화 상호작용
- 씬 전환 시 페이드 아웃/로딩/페이드 인, 일시정지 메뉴(음량·밝기 조절)
