# gameproject

Godot 4.7 기반 2D 픽셀 플랫포머 게임입니다.

## 실행 방법

1. [Godot Engine 4.7](https://godotengine.org/download) 이상을 설치합니다.
2. Godot 에디터에서 이 저장소 폴더(`project.godot`)를 프로젝트로 엽니다.
3. 에디터 상단의 실행(▶) 버튼을 눌러 `scenes/Main.tscn`을 실행합니다.

## 폴더 구조

| 경로 | 설명 |
| --- | --- |
| `scenes/` | 플레이어, 적, 아군, 체력바 등 게임 씬(.tscn) |
| `scripts/` | 각 씬/노드에 연결된 GDScript |
| `resources/` | 텍스처 및 애니메이션 프레임 리소스 |
| `assets/` | 스프라이트 이미지 등 원본 에셋 |

## 조작법

| 동작 | 키 |
| --- | --- |
| 좌우 이동 | A / D, ← / → |
| 점프 | Space, ↑ |
| 대시 | Shift |
| 공격 | J, 마우스 좌클릭 |
| 상호작용 (거울 세계 전환) | E |
| 스킬 (아군 소환) | Q |

## 주요 기능

- 이동, 점프, 대시, 공격 등 기본 액션 플랫포머 조작
- 피격 시 무적 시간 및 체력 시스템
- 거울 세계(Mirror World) 전환 기믹
- 아군 소환 스킬 (쿨다운 존재)
